# Gym Hawk design refresh — 7 November 2026

Gym Hawk now uses a warm neutral canvas, white grouped surfaces, dark forest green session cards and a restrained lime accent. System typography, consistent spacing, subtle transitions and a shared chart palette unify the app. The existing routes, programme, version-4 records, IndexedDB persistence and Cloudflare sync remain intact.

On desktop, a persistent sidebar anchors Today, Programme, Progress and Settings. A programme-week indicator lives below navigation. At phone and tablet widths, the three main destinations share a floating tab bar above the safe area. Focused workouts retain their dedicated layout and action dock.

Today introduces the day with a personal greeting, the current session, four named main-session completion states, bodyweight entry, progress and workout history. The session illustration reflects actual logged-set or programme-attempt completion. Recovery days expose optional movement and programme browsing. Bodyweight displays its actual last recorded date.

Programme offers a seven-day selector. Desktop presents the session summary beside its exercise list; phones stack them. Warm-up, settings, exercise details, the training guide, urgent guidance and week reviews remain available.

Progress retains Overview, Exercises and History. All-time totals, weekly training charts, bodyweight, attempt completion, workout feedback and volume share consistent materials. Recorded-exercise tiles retain full-history charts and exact-identity detail navigation. Charts preserve real observations, accessible tables and keyboard exploration.

Workout logging keeps one set in focus, large numeric inputs and a reachable Log set action. Rest controls, added sets, previous-session history, review, partial saving and completion have the same visual language. Settings, record details, forms and sheets use grouped surfaces and consistent controls. The app icon and installed-app chrome match the new palette.

The interface respects reduced motion, keyboard focus, modal focus restoration and safe-area/keyboard offsets. This refresh introduces no storage migration or automatic programme advancement.
